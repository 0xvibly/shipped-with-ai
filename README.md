## How this list is built

This file is **regenerated every day by [GitHub Actions](.github/workflows/update.yml)**, straight from the live [vibeking.fun](https://vibeking.fun) directory via its free public API (`GET /api/products`, no key, CORS enabled — see [the docs](https://vibeking.fun/api) or the [vibeking-api](https://github.com/0xvibly/vibeking-api) repo). Nothing here is hand-curated, so it never goes stale: **2,620 products** across **16 categories**, each section showing the top 15 by community upvotes. Last updated 2026-09-12.

Every listed URL is re-probed on a schedule, and the source API publishes the result: **2,396 confirmed live**, 47 at risk, 177 dead, 0 not yet checked. Most directories never tell you how much of their index has rotted.
